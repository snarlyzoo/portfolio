# 02 — Phase 2: showcase refresh

**Trigger:** after the in-game polish work ([03-project-polish-plans.md](03-project-polish-plans.md)) produces new visuals.

**Goal:** populate the placeholder showcase slots built in Phase 1 with real assets, turning each project page from "video + code" into "video + rich visual gallery + code."

## Work

- Drop **GIFs/short clips** of polished UI and VFX into each project's showcase gallery (e.g. wall-run with speed lines, power-meter overcharge shake, trajectory dots with bloom, particle/explosion effects).
- Add **in-game screenshots** (HUD, world, a Studio view) with good lighting/post-processing applied.
- Caption each showcase with the system it demonstrates — pair visuals with the relevant code snippet where it strengthens the story.
- Re-evaluate project ordering / featured project once polished assets exist (the flashiest project should likely lead).
- Consider a home-page **reel** stitched from the best moments across projects.

## Asset capture guidance

- Capture at high resolution; keep GIFs short (2–5s) and loop cleanly. Prefer compact formats (WebP/MP4) over heavy GIFs for web performance.
- Apply post-processing/lighting (see [03](03-project-polish-plans.md)) **before** capturing — the lighting pass is the biggest perceived-quality jump.

## Possible later additions

- `brickbattle-turf-wars` becomes a featured project once it has real gameplay to show.
- More cross-cutting visual showcases if the polish work yields strong material.
